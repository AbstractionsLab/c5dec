# Generate CRA compliance checklist

The C5-DEC software SHALL provide a command to automatically generate a CRA
compliance checklist covering all Annex I essential requirements with columns
for requirement ID, description, category, applicability, compliance status,
and evidence reference, exportable to Excel format.
