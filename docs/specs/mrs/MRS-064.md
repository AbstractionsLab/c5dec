# Generate SBOM using Syft

The C5-DEC software SHALL provide a command to generate a Software Bill of
Materials (SBOM) for a target directory or project using Syft, supporting
CycloneDX JSON and SPDX JSON output formats, and perform schema validation on
the generated artifact.
