# CC checklist creation – sequence diagram

## Description

This diagram traces the end-to-end flow when a user creates a CC evaluation checklist with `c5dec checklist --create`. The CLI dispatches to `CLIChecklistHandler`, which drives `ChecklistBuilder` to build the full CC object model from the XML database and then materialise one Doorstop work-unit item per SAR work unit in the target Doorstop document prefix.

## Diagram

```plantuml
@startuml
!theme plain
skinparam sequenceArrowThickness 2
skinparam participantBackgroundColor #FAFAFA
skinparam participantBorderColor #888888

actor "User" as user
participant "cli/main.py\n(arg parser)" as climain
participant "cli/commands.py\nrun_checklist()" as cmdfn
participant "cct.CLIChecklistHandler" as handler
participant "cct.ChecklistBuilder" as builder
participant "cct.CCDocumentBuilder" as docbuilder
database "CC XML database\n(assets/database/)" as ccdb
database "Doorstop repository\n(project root)" as doorstop

user -> climain        : c5dec checklist --create\n--id FAU_GEN --prefix CL --version 3R5
climain -> cmdfn       : run_checklist(args)
cmdfn -> handler       : CLIChecklistHandler().create(\n  version, id, prefix, info)
handler -> builder     : ChecklistBuilder().create(\n  version, id, prefix, info)
builder -> docbuilder  : CCDocumentBuilder().build(version)
docbuilder -> ccdb     : parse CC XML (SFR + SAR)
ccdb --> docbuilder    : raw XML elements
docbuilder -> docbuilder : build FClass/FFamily/\nFComponent/FElement tree\n& AClass/AFamily/\nAComponent/AElement tree
docbuilder --> builder : CCDocument object
builder -> builder     : resolve target FComponent\nor AComponent by id
builder -> doorstop    : create Doorstop document\n(if not exists)
doorstop --> builder   : document handle
loop for each WorkUnit under target component
    builder -> doorstop : add_item(prefix, text=WU.text,\n  links, attributes)
    doorstop --> builder : item UID
end
builder --> handler    : checklist document prefix
handler --> cmdfn      : success
cmdfn --> climain      : True
climain --> user       : Checklist created at CL/\n(n items)

@enduml
```
